## 使用

`qbox --task wannier-input relax.cif`、`qbox --task wannier-input scf.in`
或 `qbox relax.cif` 的主菜单 11 进入六方向菜单；
已有结果选择同名 `.win`。参数菜单提供计算项目多选、来源输入及 SCF/NSCF 输出、
原 QE 运行目录、输出文件名前缀、均匀网格、轨道投影、能窗及任务专用参数。
交互界面仅显示当前值、单位、必要的输入格式和操作提示，不自动展开理论说明。
公共设置会保留；换方向会替换任务开关。
参数主菜单只显示方向、当前项目和编号名称；当前值与默认行为统一放在对应选项内。
进入选项后，标明“首轮默认值”“已读取”或“当前值”。
已填入的必需参数不再显示“必填”；只有缺失且没有默认值的项目显示“待填写”。
进入编辑后回车直接保留显示值；可选空值明确显示“不读取”“不排除”“使用全部投影”等实际行为。

菜单 3 直接预览前缀对应的文件名。菜单 5 按编号分别设置能带数、投影和局域轨道数，
排除能带、筛选投影、迭代次数为可选项。新 SCF 来源会一次性预填首轮基组：
读取实际 UPF `PP_PSWFC/PP_CHI` 中的 s/p/d/f 原子轨道类型，按原子数量和自旋展开投影，
`num_wann` 取投影数。缺失的 `nbnd` 以投影数（加排除带）和电子容量的较大值为基础，
增加 25% 空带余量（向上取整，至少 4 条）；SCF 已明确提供且足以容纳初始基组的带数保留。
若原 SCF 的带数不足，只增大新 NSCF 的初值并提示原因，不改写原 SCF。
默认不排除能带、保留全部投影，普通任务的局域化和解纠缠最大迭代次数均采用 qbox 首轮模板值 1000。
位移电流使用局域化 1000 次、解纠缠 1200 次的初值，收敛参数可在菜单 5 → 6 中修改。
这些是可修改的试算初值，不是材料收敛参数；缺失 UPF、缺少原子轨道资料或存在当前投影语法
不能区分的同角动量多径向壳层时，会说明原因并保留手动入口，不用散射投影冒充原子轨道。
例如 Si4C4 且各元素 UPF 含一个 s 和一个 p 壳层时，预填 `C:s;p`、`Si:s;p`，
`num_wann=32`、`nbnd=40`。
菜单 6 读取完整、匹配的 NSCF 本征值时，会预填可编辑的能窗初值：
外窗覆盖未排除的能带，边界向外留 0.001 eV 后按 0.1 eV 取整；冻结窗预设为
参考能下方 5 eV 至上方 10 eV。必要时与外窗取交集并降低上界，保证各 k 点的冻结带数
不超过 `num_wann`；发生收窄时显示一条简短提示。
参考能优先使用明确填写的值或输出 EF；适用时采用已验证的采样带隙中点。
只有 HOMO 而无可靠参考能时不自动设置冻结窗。能量零点默认使用 QE 本征值零点。
这些设置是试算模板；完整 NSCF 数据不足时，保留全部能带、不启用冻结窗。
已有 Wannier 模型、手动能窗及主动清空的选择不会被初值覆盖。
菜单 6 可跳过，或分别设置外窗、冻结窗、能量零点；边界成对保存，取消不会留下半组范围。
切换能量零点会换算已有边界，保持实际能量范围。菜单 7 列出所选计算项目的专用参数，
待填项明确标出。普通参数输入 `b` 返回，填错时可在当前项重填；选择 0 或 8 时列出缺少的设置。

生成方式通过中文编号选择：`1` 从 QE 开始建立 Wannier 模型（首次使用或重建模型），
`2` 使用已经完成的 Wannier 模型生成后续分析输入。菜单会说明各自需要的文件；
回车保留当前选择，输入错误时可在原处重选。能量参考、轨道图格式、自旋分量及
是/否设置也使用编号选择；原英文选项仍可输入，JSON 配置继续使用原参数名和值。
这里仅生成输入文件，不会自动启动计算。

从 CIF 开始时，先选择六个计算方向之一，再检查当前目录已有的 SCF 输入。
优先读取与 CIF 同名前缀且结构一致的 `.scf.in`；其他名称的匹配 SCF 只有一份时
直接读取，多份时通过编号选择。读取已有文件后直接进入 Wannier 参数菜单，
保留其中的 QE 设置，不重新生成 SCF 输入。同名文件格式有误或结构不一致时，
提示从来源菜单另选文件。
没有匹配的 SCF 输入时，继续查找可复用的 NSCF 输入；两者都没有时才进入 QE 参数菜单配置赝势、截断能和 SCF k 点等，
选择 `0` 生成 SCF 输入，再继续 Wannier 参数菜单。
无需预先运行 SCF，也不要求已有 SCF 输出文件；生成的 SCF 输入位于当前目录，
即使随后退出 Wannier 菜单也会保留。同名 SCF 输入只允许换名或取消，不会直接覆盖。
CIF 转换使用与原 pw.x 输入生成相同的 Multiwfn 环境；原 CIF 保持不变。
源码入口会先加载仓库根的可选本机配置 `.qbox-local.sh`，主菜单与显式任务共用这些设置。
本机配置与环境中均未提供 `QBOX_PSEUDO_ROOT` 时，向导才会询问赝势总目录，只对本次生成生效；
该目录应包含 `QE/SSSP`、`QE/NCPP-PD04-PBE` 或 `PWmat/NCPP-SG15-PBE` 库目录。
CIF 只提供结构，不能确定目标能窗或费米能。位移电流可以先生成基础输入，
完成含空带的 NSCF 后补全占据参考能；不要求预先完成 SCF，也不必改用 smearing。
需要 SOC 的任务仍需相应 spinor QE 设置与赝势。

本版目标配置为官方 Wannier90 3.1.0；普通、共线 up/down 和 spinor 来源分别校验。
菜单 5 的有效初值可直接使用，无需逐项确认。运行环境已有 SeeK-path 时，
新来源默认采用按原晶胞生成的高对称路径，仍可在菜单 7 修改。未提供冻结窗是合法选项。
同一来源重新选择时保留手动修改；换到其他来源时重建初值，并清除旧来源的能窗、费米能和路径设置。
菜单 2 的来源和 QE 运行目录已有当前值；默认自动识别 SCF/NSCF 输出，实际 band.kpt 默认为不指定。
已有结果模式保留基础模型；改变基础模型需选择 SCF 源文件重新构建。

选择来源后，向导在当前目录、来源 SCF 所在目录及设置的 QE 运行目录中查找输出。
只有计算已完成、与来源体系匹配的 SCF/NSCF 输出才会参与选择，不能仅凭文件名或
`JOB DONE` 判定。匹配结果唯一时自动读取，多份时列出来源供选择。
明确报告的共同费米能可自动填入。位移电流还可使用经过核对的中性、非自旋极化、
固定占据 NSCF 的完整均匀网格本征值：电子数必须为偶整数且包含空带，
以最高占据带的全网格最大值和最低空带的全网格最小值检查正带隙，采用中点作为占据参考。
该值标为“采样带隙中点估计”，不会记成 QE 报告的费米能；仍需核验插值后的带隙。
只有最高占据能级、输出不完整、能带重叠或不满足上述条件时，不猜测参考值。
输出的能带数和本征值范围也仅作参考，
不直接改变已设置的基组、能窗或研究范围。手动修改（包括清空）的费米能优先。
菜单 2 可手动指定输出、输入 `a` 重新识别，或 `-` 关闭输出读取。
生成前复核所选输出，来源和读取值记录在 `.qbox.json` 与中英 README 中。
已有 `.win` 可沿用其中的费米能；自动核对新的 QE 输出还需提供原 SCF `reference_source`。
光电导、位移电流和有限频率 SHC 的 `kubo_freq_max` 初值为冻结窗绝对上限减去
后处理占据参考能。例如参考能 10.4551 eV、冻结窗上限 20.4551 eV，对应光子上限
10 eV；相对能窗先转换至 QE 零点。初值随能窗和参考能更新，手动修改或清空后停止更新。
缺少冻结窗或参考能、所得上限非正或不大于光子下限时，不自动填写。
初/末态绝对能量上限 `kubo_eigval_max` 初值取冻结窗的绝对上限，与 `.eig` 使用同一
QE 能量零点；相对能窗先换算。此初值不依赖费米能，负值也合法。它不是光子能量，
也不截断虚中间态求和。缺少冻结窗或无法确定上下自旋的共同冻结窗时不猜测初值。
两项初值在菜单 7 标为“初值”；明确输入（包括同值）或清空后，各自保留手动选择。
单独光学任务中未设置的响应上限仍可交给 postw90 的原生默认规则。
新模型允许暂缺这些响应参数而先构建模型；已有模型生成后处理输入时须补齐。
若将光子能量下限改为非零值，运行响应计算前须明确上限；新建位移电流模型时仍可暂缺上限。

生成前先核对已有 SCF/NSCF 输入、已完成输出及保存数据。已有 SCF/NSCF 输入保持原样，
不会被再次生成或加入覆盖清单；仅在没有 NSCF 输入时补充生成。
已有 NSCF 的能带数、完整均匀网格和实际 k 点顺序用于构建匹配的 Wannier 输入。
修改后的 Wannier 网格或能带数与已有 NSCF 不符时，显示冲突并停止生成，不通过覆盖 QE 输入消除冲突。
计算完成状态依据可核对的输出，保存数据的完整性单独检查；README 省略已完成且数据齐备的 QE 步骤。
只有输入、输出未能核验或保存数据缺失时，使用原输入文件名和运行目录给出后续步骤。
菜单 6 显示已读取输出的费米能、最高占据/最低未占据能级及打印本征值范围；
这些数值注明 QE 能量零点，HOMO 不会自动充当费米能。

生成文件默认位于当前目录，包括 win、pw2wan、JSON 记录、README，以及需要时补充的 NSCF。
新模型 `.win` 按参数用途分组、对齐等号；晶胞、原子、路径和 k 点坐标采用 10 位小数及
对齐列，常用参数与路径位于完整 k 点列表之前。坐标舍入误差不超过 5×10⁻¹¹，
坐标约定、原子及 k 点顺序保持；已有模型继续保留原基础文本。
菜单 `0) 立即生成输入文件` 检查通过后直接保存，不再重复询问是否保存；成功后结束本次 qbox，
与 pw.x 输入生成一致。菜单 `8` 只预览文件和检查结果；`q` 才返回 qbox 主菜单
（通过 `--task wannier-input` 直接进入时则退出）。检查不通过或取消冲突处理时仍可在参数菜单修改。
同名普通输入可统一备份后覆盖，或改 seed，或取消；备份集中存入当前目录的 `bak/`，
重复备份使用 `.bak`、`.bak.1` 等后缀，不覆盖已有备份；
非普通文件和符号链接不能直接覆盖。源 SCF、checkpoint、矩阵和波函数不作为替换目标。
预览后发布会复核目标摘要。生成仅证明输入通过静态检查，不证明物性结果或数值收敛。

非交互入口读取 JSON 对象，也支持直接读取生成的 `.qbox.json` 记录，必须显式指定冲突策略：
JSON 的 `source` 使用已配置的 QE SCF 输入或已有 `.win`；CIF 先经交互入口配置 SCF 输入。

```bash
qbox --task wannier-input --config settings.json --conflict cancel
qbox --task wannier-input --config settings.json --conflict backup
qbox kmesh 4 4 2 --format qe
qbox kmesh 4 4 2 --format wannier
```

JSON 使用 `source`、`run_root`、`seed`、`version`、`mode`、`grid`、`nbnd`、
`num_wann`、`projections`、`exclude_bands`、`windows`、`tasks`、`parameters`，
共线通道差异写入 `channels.up` / `channels.down`。路径相对于命令工作目录解释。
可选 `source_output` 指定 SCF/NSCF 输出；不指定时自动识别，`source_output_mode="off"` 可禁用。
自动化遇到多份候选且所选项目仍缺费米能时，要求明确指定输出，不静默任选一份。
`band_kpt` 指定实际 Wannier 能带点列以生成逐点 QE 对照；
已有结果下 QE 对照还需要 `reference_source` 指向原 SCF 输入。这些字段也在来源菜单内提供。
运行顺序及额外导出数据需求见每次生成的 `seed.README.txt`。
新建 `.win` 按 BERRY、WANNIER90、DISENTANGLEMENT、BANDS、DOS、TRANSPORT、
GYROTROPIC、OUTPUT、STRUCTURE、KPOINTS 分类，仅显示有内容的区域；每区以标题及
80 个 `#` 的长线分隔。投影归入 WANNIER90，路径放在使用它的 BANDS 或 BERRY 区域，
完整 k 点列表置于末尾。分区排版保留参数值、坐标格式和原始 k 点顺序。
README 采用中文在前、英文紧邻的中英对照格式，新建模型和已有结果模式均适用。
执行部分按“编号步骤 + 可直接复制的命令”排列，MPI 步骤直接使用 `mpirun -np 4`。
QE 日志沿用执行功能的命名：`scf.out`、`nscf.out`、`band.out`（`pw.x` 能带）和
`bands.out`（`bands.x` 整理）；接口日志为 `pw2wan.out`。两个自旋通道的接口与能带整理日志

QE 和 Wannier90 模块。本机使用 `module load qe/cpu/7.5 wannier90/3.1.0`，无需手动修改 PATH。

优先使用模块，不再输出 PATH 设置。生成器本身不加载环境或启动计算。
`seed.qbox.json` 是参数与来源校验记录，供追溯和复用，QE/Wannier90 不读取它。
用于 `--config` 时会直接读取其中的 `config` 对象；跨目录复用前需检查来源与运行目录路径。

若发布被强制中断，保留的 `.qbox-wannier-*/transaction.json` 可显式恢复：

```bash
qbox --task wannier-input --recover .qbox-wannier-.../transaction.json
```

该隐藏目录是同文件系统的内部事务暂存，不是额外计算目录。恢复会拒绝与后续改动冲突的文件。
