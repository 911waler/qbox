# qbox 模块化执行计划

基线：`main` 的 `6cc8155`。实施工作区：独立 `refactor/python-modules` 分支。
范围：保持科学算法、文件格式、任务编号及旧调用方式，完成渐进式模块化的可发布第一阶段。

## 设计与边界

- `qbox` 只负责定位包、选择 Python 和兼容 Bash source；Python CLI 是用户入口。
- `src/qbox/registry.py` 是 0–37 任务的编号、名称、分组及处理器注册表。
- 内嵌 Python 迁入可导入的 `io`、`postprocess` 模块；不保留字符串执行器。
- 尚未迁移到 Python 的交互及 QE/MPI 工作流按领域拆入 `legacy/*.sh`。
  保留其退出码、信号、临时文件事务和管道行为，不在本阶段改写科学工作流。
- 使用 setuptools wheel 发布完整包；源码目录启动与安装后的入口均不依赖当前工作目录。
- 保留 MIT `LICENSE`；不复制 VASPKIT 代码或分发文件。
- 不改动生产安装，不自动合并 main，不推送远端。
