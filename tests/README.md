# qbox test suite

Run the complete suite from the repository root:

```bash
bash tests/run.sh
```

Run one case file directly, for example:

```bash
bash tests/cases/test_runtime.sh
```

The development test environment requires Bash 4 or newer, GNU coreutils,
GNU findutils, GNU diffutils, `awk`, `sed`, `grep`, `timeout`, and ripgrep
(`rg`). These are test and development requirements only; they do not add a
qbox runtime dependency beyond the external tools used by its workflows.

The bare suite command uses automatic discovery. The test helper checks only
the fixed candidates `python3` and `python` on absolute `PATH` entries. Every
`seekpath` import probe is bounded by a timeout, and a failed probe is skipped.
Empty and relative `PATH` entries are ignored; generic `*-python` names are
not scanned.

The complete suite requires a Python interpreter with the `seekpath` module.
To override discovery, set `QBOX_PYTHON` to an explicitly chosen command only
after verifying that it can import `seekpath`:

```bash
export QBOX_PYTHON="your-verified-python"
"$QBOX_PYTHON" -c 'import seekpath'
bash tests/run.sh
```

An explicit value is honored and is rejected if its import probe fails; no
particular Python command is guaranteed to provide `seekpath`.

The cases source `qbox` with `QBOX_TEST_MODE=1`, so definitions load without
entering the interactive menu. Workflows execute in temporary directories and
use `QBOX_`-configured command mocks. The suite does not launch real Quantum
ESPRESSO calculations.

## Coverage

The suite checks command-line and menu dispatch, prompts, generated input and
batch files, workflow stages, post-processing data flow, convergence scans,
temporary-file cleanup, atomic writes, and public-release invariants. Golden
files compare generated bytes for supported inputs; they do not establish
scientific or physical correctness. Scientific changes still need trusted
Quantum ESPRESSO reference calculations and domain assessment.

## Scope

The tests preserve observable behavior during qbox maintenance and guard the
public release boundary. They are not a substitute for validating new
scientific methods, pseudopotentials, or production calculations.
